# WhatsNext Vision Motors – Salesforce CRM

## Project Overview
WhatsNext Vision Motors is a Salesforce CRM capstone project designed to manage vehicle-related business operations, including customer information, vehicle inventory, dealer assignment, vehicle orders, test drives, and service requests.

## Objectives
- Manage customer and vehicle information efficiently.
- Track vehicle inventory and orders.
- Automate dealer assignment for vehicle orders.
- Send test drive reminder emails.
- Automate vehicle order processing using Apex and scheduled jobs.

## Technologies Used
- Salesforce CRM
- Salesforce Flows
- Apex Programming
- Batch Apex
- Scheduled Apex
- SOQL and Salesforce Objects

## Key Features
- Customer and dealer management
- Vehicle inventory management
- Vehicle order processing
- Automatic dealer assignment
- Test drive reminder notifications
- Automated order processing and stock updates

## Salesforce Components
- Record-Triggered Flow
- Scheduled Flow
- Apex Trigger
- Apex Trigger Handler
- Batch Apex Class
- Schedulable Apex Class
